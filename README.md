# Mauricio Portela — Portfolio

Personal portfolio built with **Next.js, React, TypeScript and Sass**.

The site presents my work, projects and technical interests, with a focus on the intersection of **Cybersecurity, Network Security, Wireless and Embedded Systems**.

## Focus

- 🔐 Cybersecurity
- 📡 Network & Wireless Security
- 🧩 Embedded Systems / ESP32
- 💻 Software Development
- 🛠️ Hardware-oriented projects
- 🌐 Web interfaces and technical tooling

## Featured Projects

### WiFiCore / ESPGotchi
ESP32-based embedded security project focused on Wi-Fi monitoring, wireless data processing, storage, statistics, display and web interfaces.

The project is being developed around a modular architecture separating the Wi-Fi core from interfaces and other consumers.

### Projeto Shinobi
Game development project built with **GameMaker Studio / GML**, focused on combat systems, entities, hitboxes, enemies, gameplay mechanics and experimentation with game architecture.

## Development

Clone the repository and install the dependencies:

```bash
git clone https://github.com/Mauricios73/portfolio.git
cd portfolio
npm install
```

Start the development server:

```bash
npm run dev
```

Then open:

```text
http://localhost:3000
```

Create a production build with:

```bash
npm run build
npm start
```
